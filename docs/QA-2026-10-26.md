# Hasil QA — 26 Oktober 2026

## Cakupan dan hasil
- 15 pengujian otomatis lulus: autentikasi, pencabutan sesi, validasi PMBM, pembatasan login, konten, artikel, media, persistensi, adapter Supabase, struktur tetap, guru multi-kelas.
- Browser Edge: 11 halaman pada 1366, 768, 390, dan 320 px (44 kombinasi). Tidak ada overflow, gambar lokal rusak, error JavaScript, atau kegagalan request lokal tak terduga.
- Login admin, tambah/edit program, publikasi/pencarian artikel, album multi-foto/lightbox, video YouTube, formulir PMBM/status/ekspor CSV, navigasi ponsel, dan shell PWA offline lulus.
- Editor struktur tetap, simpan nama, tambah guru multi-kelas dan filter Kelas 1/2/6 lulus di browser. Desktop/ponsel tidak overflow.
- Semua tautan anchor HTML lokal ditemukan targetnya.
- Handler Netlify dijalankan secara lokal memakai Supabase aktual: content 200, session 200, registrations tanpa login 401. Tidak mengubah data sekolah.
- Folder dist diperiksa terhadap nilai rahasia aktif (.env): tidak ditemukan kebocoran.

## Perbaikan
1. Escape kini menutup menu ponsel, memperbarui aria-expanded dan mengembalikan fokus ke tombol menu.
2. Server lokal mengirim tipe MIME yang benar untuk JPG/JPEG, JSON, dan ICO.
3. API yang mengirim respons non-JSON kini memberi pesan yang jelas; permintaan dibatasi 20 detik. Saat konten cadangan dipakai, pengunjung mendapat pemberitahuan bahwa data terbaru belum tersedia.
4. Cache PWA diperbarui agar versi baru digunakan.

## Batas verifikasi
- Ini pengujian lokal, bukan deployment produksi Netlify. Variabel Functions, build/deploy dan domain online tetap harus diuji setelah deployment.
- Pengujian mutasi memakai SQLite sementara, bukan data sekolah. Pembacaan integrasi Supabase aktual diuji terpisah.
- Browser QA memblokir jaringan pihak ketiga: tujuan WhatsApp, pemutaran YouTube dan ketersediaan gambar eksternal tidak dijamin oleh hasil ini.
- Daftar guru belum diisi dengan data resmi. Avatar adalah placeholder.
